Say it, and it happens.

Hold two keys, say what you mean, let go. The words appear wherever your cursor is. Say the name of an app and it opens. It all runs on your own computer. Nothing you say is sent anywhere, and there is no account to make.

Download for Windows Read the privacy policy

Free. Windows 10 and 11. There is a Pro version if you use it every day.

What it does

Typing Dictate into any app in Windows: a message, an email, a document, a code editor. If there is nowhere to type, Rustle puts the words on your clipboard instead.
Commands Say the name of an app and it opens. Say “take a screenshot” or “next track” and it happens. You write the phrases yourself.
Dictionary Names it keeps getting wrong. Spell each one the way you want it written, and Rustle shows the engine your spelling before it listens.
Snippets Say a short phrase and write a long one. An address, a link, the paragraph you find yourself typing every week.
The hub Everything you have said, searchable, with what you wrote and how much. Delete any line you would rather not keep.

Nothing leaves your computer

There is no Rustle server. There is no account.

The speech recognition runs on your own machine. Your voice is never uploaded, and neither are your words.

Rustle turns speech into text using whisper.cpp, an open-source engine that runs locally. The first time you set it up, Rustle downloads that engine from GitHub and Hugging Face. A few hundred megabytes, once. After that it never needs the internet again.

The whole of what it keeps, and where, is written out on the privacy page. It is short, and worth two minutes.

Getting it

Rustle Setup.exe

About 450 KB. It installs into your own folder, so Windows never asks for an administrator password.

Windows will warn you the first time. A blue “Windows protected your PC” box appears for any program that has not yet built up a reputation with Microsoft, and Rustle is new. Choose More info, then Run anyway.

That warning is about who signed the file, not about what the file does. It will stop appearing as more people install it.

What happens on first run

Rustle asks whether to fetch the listening engine. On a computer with an NVIDIA graphics card it offers the faster version; on anything else it takes the smaller one. You can carry on using the rest of the app while it downloads, and it picks up where it left off if it stops.

What it needs

  • Windows 10 (version 1809) or Windows 11, 64-bit.
  • A microphone, and permission for desktop apps to use it.
  • About 500 MB of disk for the engine, or 1.9 GB for the graphics card version.

Questions

Does it work offline?

Yes, entirely, once the engine has downloaded. That download is the only time Rustle touches the internet.

Is it really free?

Yes. There is nothing to pay, no trial, and no account to make.

How accurate is it?

Good enough to write with. It gets better if you teach it: put the names it keeps mangling into the dictionary, and it starts spelling them your way.

Can I stop it listening?

It only records while you are holding the keys, and stops the moment you let go. Nothing is recorded at any other time.
